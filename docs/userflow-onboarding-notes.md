# Notes UX — inspiration Userflow

Sources consultées le 27 août 2026 :

- [Product Tours](https://www.userflow.com/capabilities/product-tours) : les visites guidées s’appuient sur le comportement réel des utilisateurs.
- [Product-led onboarding](https://www.userflow.com/best-practices/product-led-onboarding) : l’onboarding doit commencer par une valeur et des jalons mesurables.
- [Checklists](https://help.userflow.com/docs/checklists) : une checklist persistante permet de reprendre un parcours interrompu, d’indiquer l’avancement et de lancer une action contextuelle pour chaque étape.

Adaptation Lucepress : privilégier une checklist de trois jalons métier observables (client, devis, suivi du recouvrement), toujours relançable depuis le cockpit. Garder les visites détaillées en aide facultative afin de ne pas bloquer la première action de l’utilisateur.
